## 核心方法概述
**物理模型**：地球中心引力 + J2 一阶长期摄动（赛题式(4)）
- **搜索策略**：
  1. **Level-1 粗网格**：在由碎片根数分布确定的边界内，以均匀步长（a=100km, e=0.002, 角度=1°, M=15°）生成六维网格点，并行评估清除数；
  2. **Level-2 M 精扫**：对粗网格中清数 ≥ 5 的 Top 50 个点，固定其他 5 维，以 2° 步长精细扫描 M；
  3. **合并入库**：清数 ≥ 8 的轨道基元存入数据库。
  ## 运行方式
  window_use = 1:4;   % 计算全部四窗
  window_use = 1;     % 仅计算第一窗
