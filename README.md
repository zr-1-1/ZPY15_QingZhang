## 组合优化代码结构 ##
```
├── 参数设置（物理常数、阈值）
├── 加载数据库（orbit_base_database.mat）
├── 读取碎片（ZPY15.xml → 345 个碎片）
├── 预计算（precalc）：每个基元清除每个碎片的时刻
├── 定义目标函数（obj_fun）
├── 多次重启主循环
│   ├── 初始化种群（精英池注入 + 随机）
│   ├── 主循环：局部优化 ↔ 全局优化交替
│   └── 更新精英池
├── 输出最优方案 + 保存 + 画收敛曲线
└── 辅助函数
    ├── random_solution       生成随机解
    ├── eval_solution         目标函数
    ├── crossover_window      窗口级交叉
    ├── find_capture_times    求清除时刻
    ├── read_debris_xml       读 XML
    ├── rv2oe_si / oe2rv_v    轨道根数转换
    ├── j2sec_prop_v          J2 摄动外推
    └── wrap2pi               角度归一化
```
