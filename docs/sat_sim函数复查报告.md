## 结论

**首次检查的三个主要错误均已修复：中心引力公式、J2 分量计算、少积分一个时间步。** 对已初始化 SI 参数、三维列向量输入和整数秒整除时间的本次算例，计算结果通过核对。

## 一、仍需处理的问题

### 1. 中：数学上可整除的小数时间仍会报错

位置：`src/Data_Extract.m:272、275、277`。

```matlab
n = Tr/ts;
x = zeros(n0,n+1);
for i = 1:n
```

新注释已声明要求时间可整除，因此 `Tr=10,ts=3` 属于接口不支持的输入，不再把“不支持任意时间尾段”本身判为缺陷。但是，MATLAB 双精度下 `0.3/0.1` 不一定精确等于 3；直接将商用于数组维度会失败。

实测两个数学上满足整除约束的输入：

| 输入 | 结果 |
|---|---|
| `Tr=0.3, ts=0.1` | `MATLAB:NonIntegerInput` |
| `Tr=0.6, ts=0.2` | `MATLAB:NonIntegerInput` |

建议先检查时间为有限实数标量、`Tr>=0`、`ts>0`，再计算 `q=Tr/ts`，使用与浮点精度相称的容差判断 `q` 是否接近整数；确认后统一用 `n=round(q)` 进行分配和循环。不要只在数组维度处取整，否则循环次数仍可能受舍入影响；也不要无条件取整后接受本来不可整除的输入。

### 2. 中：输入形状和非法参数没有明确校验

位置：`src/Data_Extract.m:270–276`。

- 两个 `1×3` 行向量仍在初值赋值处触发 `MATLAB:subsassigndimmismatch`。应明确要求列向量，或者先验证各有三个有限实数元素，再用 `(:)` 统一形状。
- `ts=0` 仍触发底层 `MATLAB:nonaninf`。注释的“步长(0~Tr)”应明确是否排除零，代码应提前拒绝零或负步长。
- `Tr=0,ts=1` 当前能正确返回初始状态，但它与注释中步长不超过 `Tr` 的表述不一致；建议明确零时长为独立允许情形。
- 未校验零位置、非有限状态和全局引力参数。它们可能造成除零、非有限导数或难以定位的求解器错误。

这些属于接口稳健性问题，不影响已满足前提的列向量正常算例。

### 3. 条件性风险：全局 R_E 的单位冲突仍存在

位置：`src/model_rv.m:4、11`；`src/Data_Extract_vsl.m:16`。

`Data_Extract.m` 使用 `R_E=6378137` 米，而 `Data_Extract_vsl.m` 仍将同名全局量设成 `6378.137` 千米。在同一会话先后执行脚本，并在调用动力学前未重新初始化时，J2 中的半径平方项可能相差 `10^6`。

本次验证显式初始化了 SI 常量，未受此问题影响。后续宜统一脚本单位，并将模型参数显式传入或在入口校验，避免依赖会话残留状态。

## 二、已修复项目及验证证据

### 中心引力与 J2

当前中心引力代码为：

```matlab
g = -(mu./(norm_r)^3).*r0;
```

在标量 `norm_r` 和三维列向量状态的约定下，这与 `-mu*r0/norm_r^3` 等价，公式正确。J2 的 y、z 分量现分别从 `a_J2(2,1)`、`a_J2(3,1)` 的公共系数计算，原来的分量覆盖错误已消除。

使用 `mu=3.986004418e14`、`R_E=6378137`、`J_2=-sqrt(5)*(-4.841653717360e-4)`，对三个位置直接调用当前模型，并与独立组织的标准中心引力加 J2 分量表达式比较：

| 位置，m | 加速度差的范数，m/s² |
|---|---:|
| `[7000000;0;0]` | 0 |
| `[0;7000000;0]` | 0 |
| `[4000000;5000000;3000000]` | 0 |

这里的零指本次双精度计算中的差值，不代表模型与真实环境无误差，也未检验参考坐标轴与 ATK 的对齐。

### 时间终点与列数

使用零引力匀速算例 `r0=[7e6;0;0]`、`v0=[0;1;0]`、`mu=J_2=0`，精确解为 `y(t)=t`：

| 输入 | 输出尺寸 | 末列位置 y 的误差，m |
|---|---|---:|
| `Tr=10,ts=1` | `6×11` | 1.95e-14 |
| `Tr=1,ts=1` | `6×2` | 1.11e-16 |
| `Tr=0,ts=1` | `6×1` | 0 |

因此对于这些输入，原先少一步的问题已消除，`Tr=ts` 也会完成一次积分。

### 无摄动圆轨道解析比较

设置 `J_2=0`，初始位置为 `[7e6;0;0] m`，初始速度为 `[0;sqrt(mu/7e6);0] m/s`。以角速度 `sqrt(mu/a^3)` 的圆轨道解析状态核对当前位置与速度，调用的是原样提取的当前 `sat_sim` 和项目中的当前 `model_rv`，保留默认求解器选项。

24 小时、60 秒间隔算例中，采样点的最大比机械能相对变化约 `5.79e-13`，最大角动量向量变化范数相对于初始角动量范数约 `2.90e-13`。

这支持修复后中心引力与积分流程在上述算例下工作正常。当前每段重新启动 `ode45`，改变 `ts` 也会影响内部步长选择和误差；不能把上述数值当作任意步长、偏心率或含摄动轨道的精度保证。
