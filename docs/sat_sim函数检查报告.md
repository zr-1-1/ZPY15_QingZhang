# sat_sim 函数检查报告

> 本文保留首次检查时的代码状态与证据。用户修复后的最新结论见 [sat_sim 函数复查报告](sat_sim函数复查报告.md)：三个主要错误已修复，仍有浮点时间参数及接口稳健性问题。

检查日期：2026-09-10。检查对象：当前工作区 `src/Data_Extract.m:264–277` 及其直接依赖 `src/model_rv.m`。检查方式：静态审查、MATLAB R2023b 隔离验证、官方文档核对。

## 结论

**当前实现不能用于可信的轨道传播。** 已确认中心引力公式错误、J2 分量计算错误和传播终点少一个时间步；此外，时间参数与输入形状缺少明确约束。前两个错误位于被调用的 `model_rv.m`，即使只修复 `sat_sim` 的循环，结果仍然不正确。

仓库中搜索到的 `sat_sim` 只有定义，没有调用。它是脚本局部函数，当前脚本中的碎片传播循环调用的是 `OE_scl_ptb`，因此不能把本报告的问题直接归因到现有 `D_Eall` 结果上。局部函数也不能像独立 `sat_sim.m` 一样供其他文件直接调用；若计划作为公共仿真接口，需要另行明确组织方式。

本次只新增报告，未修改源代码、已有数据或用户改动；没有运行会连接 ATK、写入数据及执行大规模传播的完整脚本。

## 一、已确认的问题

### 1. 严重：中心引力分母少了距离平方

位置：`src/model_rv.m:10`，由 `src/Data_Extract.m:274` 调用。

当前代码：

```matlab
g = -mu./(norm_r).*r0;
```

应使用：

```matlab
g = -mu / norm_r^3 * r0;
```

中心引力的向量形式为 `-mu*r/|r|^3`。现有表达式的量纲也不是加速度。设 `mu=3.986004418e14`、`r=[7e6;0;0] m`、`J_2=0`，直接调用当前 `model_rv` 得到：

| 项目 | x 方向数值 |
|---|---:|
| 当前计算 | -3.986004418e14 |
| 正确加速度，m/s² | -8.13470289387755 |
| 同一 SI 数值输入下的比值 | 4.9e13 |

影响：初始加速度即已失真，任何基于此模型的真实轨道积分都不可信；调整积分步长或容差无法修复物理公式错误。[公式依据：MathWorks 轨道传播方法](https://www.mathworks.com/help/aeroblks/orbit-pop-algorithms.html)。

### 2. 严重：J2 的 y、z 分量误用了已计算的 x 分量

位置：`src/model_rv.m:11–14`。

第 11 行将三个分量初始化为公共系数 `k`，第 12 行把 `a_J2(1,1)` 改成了完整的 x 加速度。第 13、14 行继续把它当作公共系数，分别乘上 y、z 对应的长度项，导致多乘一个与 x 有关的因子，且量纲错误。

以 z 轴为模型对称轴，记 `R=norm(r0)`、`q=5*(r0(3)/R)^2`，正确的公共系数与分量组织为：

```matlab
k = 1.5 * mu * J_2 * R_E^2 / R^5;
a_J2 = k * [r0(1)*(q-1); r0(2)*(q-1); r0(3)*(q-3)];
```

为避免错误中心引力的大数值掩盖微小摄动，验证时在临时工作区**原样执行模型第 11–14 行**，单独读取 `a_J2`。参数使用脚本中的 SI 常量。

| 位置，m | 当前 J2 向量 | 正确 J2 向量，m/s² |
|---|---|---|
| `[0;7000000;0]` | `[0;0;0]` | `[0;-0.0109673900361;0]` |
| `[4000000;5000000;3000000]` | `[-0.000595841062252;297.920531126;3753.79869218]` | `[-0.000595841062252;-0.000744801327814;-0.00938449673046]` |

影响：即使修复中心引力，J2 仍会给出错误方向与量级；在 `x=0` 的位置还可能错误地让全部摄动消失。建议将公共系数保存在单独标量中，避免分量覆盖。

### 3. 高：传播少一个时间步，终点没有达到 Tr

位置：`src/Data_Extract.m:267–275`。

```matlab
n = Tr/ts - 1;
x = zeros(n0,n+1);
for i = 1:n
```

当 `Tr/ts=N` 为正整数时，含初始状态的结果应有 `N+1` 列、积分 `N` 次；当前只有 `N` 列、积分 `N-1` 次，最后状态对应 `Tr-ts`。

第 268 行建立的 `time=(0:ts:Tr)'` 有 `N+1` 个点，却没有参与积分、索引或返回，因此不会纠正错误，其注释中的点数也与 `n` 定义不一致。

隔离验证：令 `mu=J_2=0`，使用 `r0=[7e6;0;0]`、`v0=[0;1;0]`，此时精确解满足 `y(t)=t`，可不受错误重力公式影响地验证时间逻辑。

| 输入 | 当前输出 | 预期 |
|---|---|---|
| `Tr=10, ts=1` | `6×10`，末列 `y=9` | `6×11`，末列 `y=10` |
| `Tr=1, ts=1` | `6×1`，末列 `y=0`，未积分 | `6×2`，末列 `y=1` |
| `Tr=86400, ts=1` | 静态推导：末列时刻 86399 s | 末列时刻 86400 s |

影响：按总时间解释末列状态时，会产生一个输出时间间隔的时刻误差；与其他轨迹对齐时也会少一列。

### 4. 中：非整除时间参数报错，输入契约不完整

位置：`src/Data_Extract.m:267–271`。

数组列数直接使用 `Tr/ts`，没有检查整数性，也没有定义末尾不足一个步长的处理方式。实测：

| 输入 | 结果 |
|---|---|
| `Tr=10, ts=3` | `MATLAB:NonIntegerInput` |
| `Tr=0.5, ts=1` | `MATLAB:NonIntegerInput` |
| `Tr=1, ts=0` | `MATLAB:nonaninf` |
| `Tr=0, ts=1` | 返回 `6×1` 初始状态；本例未报错 |

因此不能笼统声称 `Tr=0` 必然出错。建议明确选择：允许最后一个短步并到达 `Tr`，或者要求整除并提前给出可读错误；不要简单使用 `floor(Tr/ts)` 后静默丢掉尾段。时间网格应作为分配、积分和输出的共同依据，并处理浮点舍入与终点重复。

### 5. 中：行向量输入无法赋值，状态与全局参数缺少校验

位置：`src/Data_Extract.m:271`；`src/model_rv.m:4–10`。

`x(:,1)=[r0;v0]` 实际要求两个输入都是 `3×1` 列向量。两个 `1×3` 行向量会拼成 `2×3`，实测触发 `MATLAB:subsassigndimmismatch`。当前函数注释没有说明此约束。

建议检查每个输入恰有三个有限实数元素，再通过 `r0(:)`、`v0(:)` 统一为列向量；同时验证 `norm(r0)>0`、`Tr>=0`、`ts>0`。物理传播入口还应检查 `mu`、`R_E`、`J_2` 已初始化且满足约定，测试专用零引力情形另行处理。

单位风险：`Data_Extract.m` 将全局 `R_E` 设为米，`Data_Extract_vsl.m` 则仍将同名变量设为千米。若在同一 MATLAB 会话切换脚本后调用本模型而未重新初始化，J2 中的 `R_E^2` 因子会差 `10^6`。这是条件性全局状态污染风险；不是已按 `Data_Extract.m` 正确初始化时必然发生的问题。

## 二、条件性风险及改进建议

1. **每段时间从零开始**（第 273 行）：当前 `model_rv` 不使用 `t`，属于自治系统，因此分段使用 `[0,ts]` 本身不会额外改变当前微分方程的解。若以后加入按绝对时间变化的推力或环境参数，就会错误地重复首段时间，应使用真实的相邻采样时刻。

2. **取末行方式不稳健**（第 275 行）：`length(xx)` 是最大维度，只有当输出行数不少于 6 时才等于末行号；更清晰可靠的是 `xx(end,:).'`。本次正常短时算例没有复现此处越界，不把它列为必现故障。

3. **未检查积分是否到达段末**（第 274–275 行）：`tt` 没有使用。如果求解器因数值困难警告退出并返回部分轨迹，代码仍会把其末行当作完整时间段末状态。应检查实际终止时间，并对非有限状态明确失败。

4. **采样间隔与内部积分步长混淆**：`ts` 控制每次调用的时间区间；`ode45` 内部自适应选择步长，并非固定步长积分器。通常可以用一次积分及指定输出时间点减少重复启动开销；若只给两个时刻，`ode45` 会返回内部输出点，不能直接假定转置后只有两列。单点 `Tr=0` 也需独立处理。[依据：MathWorks ode45](https://www.mathworks.com/help/matlab/ref/ode45.html)。

5. **没有显式精度配置与误差验收**：当前传入 `[]` 使用默认选项。默认 `RelTol=1e-3`、`AbsTol=1e-6` 是局部误差控制参数，不代表全天位置精度保证，也不能直接换算成终点位置误差。修复公式后应根据位置、速度的目标精度设置容差，并进行收敛验证。[依据：MathWorks odeset](https://www.mathworks.com/help/matlab/ref/odeset.html)。

6. **模型适用边界**：中心引力加 J2 是简化模型；未使用 `w_E` 本身不构成惯性系、固定对称轴 J2 模型的错误。若目标是复现含高阶重力或阻力的 ATK 轨迹，应另行核对参考坐标系、地轴方向、历元和力模型，本次未验证与 ATK 的等价性。
